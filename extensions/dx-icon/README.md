# DX Icon

DX-branded Material Design icons for DX Code's Project Panel and tabs.

Derived from zed-extensions/material-icon-theme v1.3.1 and rebranded as DX Icon for the DX Code default icon theme.

The icons are sourced from the [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme) for VS Code and are distributed under their original [LICENSE](./LICENSE). Keep the upstream license and icon attribution with this extension.
